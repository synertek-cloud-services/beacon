# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues, pull
requests, discussions, logs, or screenshots.

Use [GitHub's private vulnerability reporting](https://github.com/synertek-cloud-services/beacon/security/advisories/new)
to share the affected component and version, reproduction steps, impact, and
any suggested mitigation. Remove unrelated credentials, device tokens,
signing keys, personal data, and customer information from the report.

We will acknowledge the report, investigate its impact, and coordinate any
fix and disclosure through the private advisory. Please do not disclose the
vulnerability publicly until that coordination is complete.

## Supported versions

Beacon is under active development. Security fixes are applied to the current
release line; older releases may require upgrading to receive a fix.
